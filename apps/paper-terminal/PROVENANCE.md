# Sources

The Coil/AppKit terminal boundary (`src/terminal.coil`, `src/ghostty.coil`, `src/objc.coil`, and the supporting native definitions) was adapted from the local `jim-coil-rewrite` project, inspected at commit `b37ba0466e01d7f2f2e5b4012b92f708375485fa`. Its functioning Ghostty integration provided the reference for keyboard interpretation, NSTextInputClient, mouse input, clipboard, and C ABI callbacks. The Paper app owns its own tab lifecycle, material/layout, resource packaging, and menus.

Ghostty source is pinned to [`7aa9591746ffa4d2eee458960c76554352832595`](https://github.com/ghostty-org/ghostty/tree/7aa9591746ffa4d2eee458960c76554352832595), the revision used by that Jim setup. `scripts/prepare-ghostty.py` downloads and builds the pristine upstream tree. It verifies the public header against `vendor/ghostty.h`; no private session or multiplexer patch is applied. Ghostty is MIT-licensed; its license is retained in `vendor/GHOSTTY-LICENSE` and in the application bundle. Ghostty's bundled dependencies retain their upstream licensing in its source tree.

The implementation uses the public `ghostty_surface_new` embedding API and Ghostty-owned PTYs. There is no runtime dependency on the Jim repository, a Jim service, Sieve, or an installed Ghostty.app.

Theme and cursor integration follow the official [Ghostty configuration reference](https://ghostty.org/docs/config/reference), including transparent default cell backgrounds and the documented cursor uniforms for custom shaders. The layout and paper renderer are the local libraries in this repository. The app icon is generated by `src/icon.coil` using those same Paper primitives.
